# infer-ci 소개

**Language / 언어:** [English](README.md) | **한국어**

infer-ci는 모델 평가 지표와 신뢰구간을 함께 계산하는 Python 라이브러리입니다. 지표값뿐 아니라 평가 결과의 불확실성도 확인할 수 있습니다.

## 시작하기

- [설치](getting-started/installation.ko.md): Python 요구 버전, 가상환경 설정, 일반·개발용 설치 방법
- [빠른 시작](getting-started/quickstart.ko.md): 첫 분류·회귀 평가, 입력값과 반환값, 신뢰구간 계산 예제
- [예제 (English)](getting-started/examples.md)
- [API 문서 (English)](api-docs/index.md)

현재 한국어로 제공하는 상세 문서는 설치와 빠른 시작입니다. 나머지 문서는 영어로 제공하며, 각 페이지의 언어 링크로 영어·한국어를 이동할 수 있습니다.
