# Contributing to infer-ci

Thank you for contributing! The full guide is in [docs/dev/contributing.md](docs/dev/contributing.md): development setup, running tests, code style, adding a new metric, and the pull request process.

In short:

1. Fork the repository and create a branch from the latest `dev`.
2. Make your change, with tests (`python -m pytest tests/`).
3. Open a pull request to `humblebeeai/infer-ci`, base branch `dev`, and fill in the PR template.
