# ChokePoint 얼굴 출석 평가 (`P2E_S1_C3`)

## 1. 문제 정의
ChokePoint 비디오 시퀀스(`P2E_S1_C3`)를 대상으로 얼굴 기반 출석/식별 예측 결과가 실제 정답(Ground Truth) 신원(ID)과 얼마나 일치하는지 평가합니다. 영상 프레임 자체를 다시 처리하지 않고, 정답 XML 어노테이션과 사전 생성된 예측 CSV(`P2E_S1_C3.csv`)를 기준으로 지표와 95% 신뢰구간을 산출합니다.

## 2. 실험 구성
- **데이터셋 및 시퀀스:** ChokePoint `P2E_S1_C3`
- **입력 파일:** 정답 압축 파일 `groundtruth.tar.xz` (약 `0.5 MB`) 및 예측 결과 `P2E_S1_C3.csv`
- **평가 지표:** Ground Truth ID Match Rate
- **실행 환경:** Python 3.10 기반 가상환경(`.venv`)에서 `run_eval.py` 및 `chokepoint_attendance.ipynb` 실행

## 3. 결과 표

| Sequence | Metric | Samples (N) | Rate | 95% CI Lower | 95% CI Upper |
| :--- | :--- | ---: | ---: | ---: | ---: |
| P2E_S1_C3 | GT ID Match Rate | 2247 | 0.7583 | 0.7406 | 0.776 |

## 4. 신뢰구간이 알려 주는 것
- `2,247`개 평가 샘플 기준 전체 매칭률은 `0.7583`(`75.83%`)이며, 95% 신뢰구간은 `[0.7406, 0.7760]`(`74.06%` ~ `77.60%`)입니다.
- 표본 수가 `2,247`개로 비교적 크기 때문에 신뢰구간 폭이 약 `0.0354`(`3.54%p`)로 좁게 형성되어, 실제 모비율의 불확실성이 크지 않음을 보여 줍니다.
- 약 `74.1%`~`77.6%` 구간에 머물러 있으므로 출석 자동화 시스템으로 바로 쓰기에는 오인식/미매칭 사례를 줄이기 위한 추가 개선 여지가 있음을 함께 확인할 수 있습니다.
